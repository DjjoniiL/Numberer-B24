# Нумератор сделок - свои правила генерации

Bitrix24 Marketplace-приложение для автоматической нумерации сделок. Приложение создает пользовательское поле `Уникальный номер` (`UF_CRM_UNIQUE_NUMBER`) и заполняет его по правилам администратора портала.

## Что умеет приложение

- Создает поле сделки `UF_CRM_UNIQUE_NUMBER`, если его еще нет.
- Добавляет поле `Уникальный номер` в карточку сделки.
- Генерирует номера только для сделок в выбранных стадиях и в выбранных воронках.
- Учитывает дату начала выборки и не трогает сделки, созданные раньше этой даты.
- Не перезаписывает уже выданные номера.
- Поддерживает ручной префикс, префикс из строкового поля сделки или работу без префикса.
- Позволяет выбрать разделитель после префикса: `_`, `-` или без разделителя.
- Позволяет включать или выключать буквенную часть номера.
- Поддерживает цифровую часть на 3, 4, 5 или 6 цифр.
- Поддерживает буквенную часть на 2, 3, 4 или 5 латинских букв.
- Поддерживает последовательный и случайный режим генерации.
- Позволяет задать свой стартовый номер.
- Может вести общий счетчик для всех воронок или отдельные номера по каждой воронке.
- Исключает номера с нулевой цифровой частью, например `AA0000`.
- Показывает журнал логирования с настройками, фильтрами выборки и результатом обработки.
- Содержит окно помощи для пользователя.

## Формат номера

Примеры поддерживаемых форматов:

```text
FSB-AA0001
FSB_AA0001
FSBAA0001
AA0001
FSB-0001
0001
```

Номер состоит из:

- префикса сделки, если он включен;
- выбранного разделителя, если он включен;
- буквенной части, если она включена;
- цифровой части.

При последовательной генерации приложение пропускает нулевые значения цифровой части. После `AA9999` следующим номером будет `AB0001`, а не `AB0000`.

## Основные настройки

### Источник префикса

Администратор может выбрать:

- `Задать вручную` - один общий ручной префикс;
- `Взять из строкового поля сделки` - префикс берется из выбранного поля конкретной сделки;
- `Без префикса` - номер состоит только из буквенной и цифровой частей.

Если выбран префикс из поля сделки, но поле пустое, номер не создается. В таймлайн сделки добавляется комментарий с причиной.

### Стартовый номер

Опция `Свой стартовый номер` позволяет начать последовательность с заданного значения, например:

```text
AD999
FSA008790
```

Приложение автоматически подстраивает количество букв и цифр под введенный стартовый номер, если формат поддерживается.

### Счетчик по воронкам

Переключатель работает так:

- включен - отдельные номера на воронку;
- выключен - общий счетчик для всех воронок.

В режиме отдельных номеров проверка дублей ограничивается текущей `CATEGORY_ID`, поэтому разные воронки могут иметь одинаковую цифровую последовательность.

## Обработка сделок

При сохранении настроек приложение:

1. Сохраняет настройки в `app.option`.
2. Создает новую ревизию правил.
3. Сбрасывает состояние последовательности для новой ревизии.
4. Выбирает сделки по воронке, стадии и дате создания.
5. Пропускает сделки с уже заполненным `UF_CRM_UNIQUE_NUMBER`.
6. Проверяет доступность сделки через CRM API.
7. Генерирует уникальный номер.
8. Записывает номер в поле сделки.
9. Сохраняет состояние последовательности.

Фоновый worker продолжает обработку активной ревизии и проверяет новые подходящие сделки. Интервал опроса: `1500ms`.
