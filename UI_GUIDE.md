# UI Guide

## Общий стиль

Интерфейс встроен в iframe Bitrix24 и должен быть спокойным рабочим экраном настроек, без маркетингового hero-блока.

## Структура

- Верхняя панель: название приложения, домен портала и кнопка обновления справочников.
- Основная панель: настройки номера, выбор даты, формат, режим, стадии по воронкам.
- Пример номера расположен внутри основного блока справа от выбора цифровой и буквенной частей.
- Для неадмина над настройками показывается предупреждение о необходимости обратиться к администратору.

## Компоненты

- Для выбора режима используются segmented controls.
- Для бинарной административной доступности используется disabled state всех полей.
- Для справки по комбинациям используются круглые кнопки `?` и modal dialog.
- Карточки не вкладываются друг в друга.

## Текст

Пользовательский текст должен быть коротким и прикладным. Не показывать REST-методы, SDK, worker, zip hygiene и внутренние runtime-подробности в основном UI.

## Responsive

На узких экранах сетка перестраивается в одну колонку; текст в кнопках и preview не должен вылезать из контейнера.
