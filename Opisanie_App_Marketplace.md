# Описание приложения для Marketplace

## Полное описание приложения

Нумератор сделок автоматически присваивает сделкам уникальные номера по правилам вашей компании. Администратор выбирает воронки, стадии запуска, источник префикса, разделитель после префикса, длину цифровой части, буквенную часть, режим последовательной или случайной генерации, область счетчика по воронкам, а также дату начала выборки.

Приложение создает в сделке поле «Уникальный номер» и помещает его в основной раздел карточки. Номер может формироваться в формате `ПРЕФИКС_AAA0001`, `ПРЕФИКС-AAA0001`, `ПРЕФИКСAAA0001`, `AAA0001`, `ПРЕФИКС_0001` или `0001`: префикс можно задать вручную, взять из строкового поля сделки или отключить. После изменения настроек администратором приложение выдаёт номера только подходящим сделкам с пустым полем «Уникальный номер». Ранее выданные номера сохраняются и не перезаписываются.

Настройки доступны только администраторам портала. Остальные пользователи видят сообщение о необходимости обратиться к администратору.

## Процесс установки

Установите приложение из Marketplace и завершите установку в окне Битрикс24. После установки администратор открывает приложение, проверяет дату начала выборки, префикс, разделитель, буквенную и цифровую части, режим генерации, общий или отдельный счетчик по воронкам и стадии запуска по воронкам, затем нажимает «Сохранить».

По умолчанию используется ручной префикс `NUM`, 2 буквы, 4 цифры, последовательный режим, успешная стадия во всех воронках и дата выборки за две недели до даты установки.
