# Next Prompt

Проект: `G:\AI Project B24\Numberer B24`.

Приложение: Bitrix24 Marketplace static app `Нумератор сделок - свои правила генерации`, runtime label `Нумератор сделок - свои правила генерации v.5`.

Текущий финальный zip: `dist app B24 zip/Numberer B24 v.5.zip`.

Ключевое поведение:

- Scope: `crm`, `placement`, `user_brief`.
- Настройки меняют только администраторы через `BX24.isAdmin()` / `user.admin`.
- Неадмин видит строку: `Для изменения настроек обратитесь к администратору вашего портала.`
- Настройки сохраняются в `app.option` и не сбрасываются при открытии/обновлении.
- Дефолты: ручной prefix `NUM`, 4 цифры, 2 буквы, последовательный режим, дата выборки минус 14 дней от установки, успешная стадия во всех воронках.
- При сохранении админом нумеруются только подходящие сделки по стадии и `DATE_CREATE`, где `Уникальный номер` пустой.
- Ранее заполненные номера сохраняются, не очищаются и не перезаписываются.
- Удалённые или недоступные сделки отсекаются через `crm.item.get`.
- Worker обрабатывает только подходящие сделки без номера.
- Если выбранное поле префикса пустое, номер не создаётся и добавляется комментарий в таймлайн.
- `v.5` исключает номера с нулевой цифровой частью во всех режимах: после `AA9999` идет `AB0001`.
